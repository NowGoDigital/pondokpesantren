Publikasi Konten ke Website

Kirim seluruh konten CMS (berita, agenda, galeri, prestasi, profil, pengaturan, status pendaftar) menjadi satu file cms-data.json agar terlihat di semua browser & perangkat — sekarang via GitHub, nanti via Hostinger tanpa ubah kode.

Buat di GitHub → Settings → Developer settings → Personal access tokens. Scope: repo (atau Contents: Read & write).

Status Publikasi Terakhir

Belum pernah publikasi.

Setelah publikasi sukses, tunggu ±1 menit (GitHub Pages rebuild), lalu buka website di browser/perangkat mana pun — konten baru sudah tampil.

Zona Berbahaya
